# Macros

Macros for WoW Forever and Classic WoW, one folder per class.

| Class | Covers |
| --- | --- |
| [Warrior](warrior/README.md) | Stance dancing, PvE tanking and DPS, PvP, and how Forever's stance swapping differs from Classic |

## Using a macro

1. Type `/macro` in game, click **New**, pick the question-mark icon, and
   name it.
2. Paste the macro text (255 characters at most).
3. Drag the macro to your action bar.

Each macro says whether it works on **Forever**, **Classic**, or **Both**.
